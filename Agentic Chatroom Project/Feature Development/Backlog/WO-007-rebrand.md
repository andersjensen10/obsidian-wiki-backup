# Rebrand

## Vision
"Agora" and "Agentic Chatroom Project" won't carry the product toward
either an open-source community or a commercial release — neither name
says what the thing is. The Board wants this done early and deliberately,
specifically to minimize how much later sprint work (docs, code comments,
published-feature writeups, this vault's own naming) has to be reconciled
after the fact. It shouldn't block the other initiatives, but shouldn't
drift indefinitely either.

## Goal
A new product name (and a minimal visual identity — not a full brand
system) decided, and an initial pass applied to the highest-visibility
surfaces: live product UI and top-level vault/project naming. Not a mandate
to rewrite historical published-feature writeups.

## Success metric
Rebrand decision documented and applied to the live UI and top-level vault
naming without delaying or blocking the Worlds & Scenes or other
initiative sprints already in flight.
