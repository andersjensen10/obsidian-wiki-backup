# World Session Configuration, Player Character & Safety

## Vision
The near-term direction makes World creation a guided collaboration: a user describes a setting and roleplay premise in natural language, then approves the consequential choices before play begins. A persistent player-character reference and enforceable content boundaries give personas and the narrator a coherent, safe basis for treating the user as someone inside the fiction rather than an abstract chat participant.

## Goal
A user can create and subsequently edit a World Session with its premise, genre, tone, boundaries, player character, and explicit age-gated adult-content choice; the established configuration consistently informs the active scene and its participants.

## Success metric
A new user completes configuration and begins a scene with a player character and stated boundaries visible/editable afterward; attempts to enable adult themes without an explicit over-18 confirmation are blocked, and the configured constraints demonstrably reach narrator/persona context.
