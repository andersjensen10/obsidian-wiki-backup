# Onboarding — configuration wizards

## Vision
This is the accessibility half of pushing capability further while making
it more approachable. Every persona/World/Narrator setting must stay fully
editable at full depth — nothing here reduces capability — but the entry
point to that depth should be a guided Quick Start path that gets a new
user to a working persona/scene fast. The Board flags this as low-dependency,
UI-primarily work, a good parallel track alongside the heavier
architectural initiatives.

## Goal
A guided Quick Start wizard flow that produces a working persona/scene
without requiring the full-detail editor, while the full-detail editor
remains available underneath for anyone who wants it.

## Success metric
A first-time flow completes persona/scene creation via the wizard alone (no
full editor touched) in a live/manual check, and the full editor still
exposes every field the wizard set, with no functionality lost.
