# Scene media & the studio

> [!note] Matured — 2026-09-10
> Scrummaster matured this work order's first layer (in-scene POV image
> requests + minimal media library) into
> [[FR-012-scene-media-and-library]]. Post-scene video recreation and the
> LTX-vs-Fish TTS comparison described below are later layers of this same
> arc and were deliberately left for future stories — see that story's
> Non-goals section. This file is kept as the archived source record.

## Vision
Media generation should become part of how a scene is experienced and kept,
not a side action: in-scene POV/third-person image requests through a
configurable interaction, post-scene video recreation delivered to an
editor, and TTS voice generation (LTX vs. Fish, compared rather than
assumed). Over time this accumulates into a per-user, remixable media
library tied to the Worlds and scenes that produced it. The Board frames
this as a multi-sprint arc maturing in layers — generation, then library,
then editing — not a single feature.

## Goal
First layer only: in-scene image generation requests (a specific
character's POV, or third person) through an easy, configurable UI action
— not a raw prompt box — plus a minimal media library that stores what's
generated and ties each item back to the World/scene that produced it.

## Success metric
A user can request and receive a scene image from a named character's POV
without touching a raw prompt box, and retrieve it afterward from a
per-user library view scoped to the originating World/scene.
