# Scene Media Studio — Video, Narration & Editing Layer

## Vision
Scene media should become a retained, editable part of a user's World history rather than a one-off generated attachment. The next layer builds from in-scene image generation and library persistence toward post-scene recreation, narration/dialogue experimentation, and intuitive editing.

## Goal
Enable a user to request a post-scene video recreation into an editor-oriented media flow, retain associated media under its World/Scene, and establish evidence-based comparison of available voice-generation approaches for scene narration/dialogue.

## Success metric
A completed scene can produce a retrievable video recreation that opens into an editing-oriented experience rather than a raw file drop; a documented live comparison of candidate narration/voice paths identifies the supported approach and its quality/operational trade-offs.
